ANGEL ONE CHART ANALYSIS BOT

SAFE MODE ONLY:
This project downloads Angel One historical candles and calculates EMA20, EMA50, RSI14, MACD, ATR14 and VWAP-style analysis. It prints a technical state and saves a CSV report. It does NOT place live orders.

1) Install Python 3.11+
2) Copy .env.example to .env
3) Fill your own SmartAPI credentials in .env
4) Install: pip install -r requirements.txt
5) Run: python bot.py

Never share your .env, API key, PIN, TOTP secret, access token or refresh token.
Before live order execution, Angel One requires a registered static IPv4 for order APIs.
